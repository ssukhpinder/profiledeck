## [Unreleased]

### Added

- Open-source project documentation, policies, contribution guidance, issue
  forms, and continuous-integration workflows.

## [0.1.0] - 2026-07-25

### Added

- Universal ProfileDeck plugin manifest and local development marketplace.
- Profile-router, Personal assistant, and Work assistant skills.
- Default Personal and Work profile definitions.
- Profile-aware routing decisions for skills, connectors, and operation classes.
- Explicit allow, confirm, and deny results with native-authorization reminders.
- Revision-checked profile updates.
- Expiring contexts pinned to immutable profile snapshots.
- Local JSON persistence with atomic writes.
- Bundled stdio and deployable Streamable HTTP MCP transports.
- Policy, store, and MCP contract tests.
